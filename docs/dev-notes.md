# Maintainer notes

Facts for working on fbktop that the README doesn't cover.

## Repo

- `origin` = `MinaFBK/fbktop` (private), branch `main`. `upstream` = aristocratos/btop with push
  disabled. GitHub forks can't be private, so this is a standalone repo that carries upstream's
  history; merge upstream fixes from `upstream`.
- Renamed from the btop patch on 2026-11-16. Only user-facing names changed (command, config, log,
  banner, icon); internals stay `btop_*` so upstream merges stay clean.

## Gpu% column

- Code: `src/linux/btop_gpuproc.cpp` (commit 882c280). Value = busiest engine from DRM fdinfo.
- fd scan: once when a pid appears, then only if the process used CPU and 5 updates have passed
  since its last scan (30 if it already has a GPU client).
- Checked against an independent fdinfo script: within 1-2 points. Cost: about +0.01-0.03 s CPU
  per 40 s.
- Load testing without a display: EGL surfaceless + GLES loaded with `dlopen` (this machine has no
  ffmpeg or EGL headers).

## Header bar design

- Commit b650439. Bar = theme bg blended 70% toward inactive_fg; sorted-cell tint = bar blended 25%
  toward hi_fg.
- Underlined headers were rejected as the "clickable" cue (not intuitive). The button bar was chosen
  from a PNG mockup drawn over a real terminal capture.
- Startup sort comes from `proc_sorting` (config file or options menu). Key and click sort changes
  are session-only (8c506fa, 882c280).

## Icon

- Generated by `Img/gen_logo.py` ("fBk": lowercase f/k, taller capital B).
- Render PNGs with cairo. ImageMagick's SVG renderer drops strokes.
- After changing the icon on a desktop install: copy it to
  `~/.local/share/icons/hicolor/{scalable,48x48}/apps/`, then `gtk-update-icon-cache -f -t` on that
  theme dir.

## Testing

- The pyte terminal emulator doesn't render btop's menu overlay. Inspect the raw output instead.
